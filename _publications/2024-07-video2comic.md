abstract: Dynamic comics are widely used in video production because they enable people to efficiently summarize video sequences. However, its design process is currently done manually and requires special skills such as segmenting video sequence and layout, which often makes it inaccessible to people, especially novices. In this paper, we propose an interactive tool that allows users to convert input videos into dynamic comics. First, the user specifies the segmentation points while watching an input video. The system then automatically computes the locations of comic panels using a parametric layout model and composites the set of video segments. To investigate the effectiveness of the proposed system, we conducted a user study where people used our system and provided feedback on dynamic comic design tools.
